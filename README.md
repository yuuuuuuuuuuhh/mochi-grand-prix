# モチモチグランプリ

おもちの「モチ」と食べものレーサーたちで走る、ブラウザで遊べる3Dカートレースです。
インストール不要。ページを開くだけで遊べます（パソコン・スマホ対応）。

## 遊び方

| 操作 | キー |
|---|---|
| アクセル / ブレーキ | ↑ / ↓（W / S） |
| ハンドル | ← →（A D） |
| ドリフト | スペース（押しながら曲がり、離すとダッシュ） |
| アイテム | E / X（バナナの皮と甲羅は押している間うしろに持つ） |
| ポーズ | P / Esc |
| 音楽オン・オフ | M |

- モード: 1人（CPU 11台）、2人画面分割、オンライン対戦（同じ4桁のルーム名で入る。足りない分はCPU）
- ステージ: 渋谷ナイト / 南国ビーチ / 桜の古都 / 雪のアルプス / 星降る雪の街 / もちもちワンダーパーク
- もちもちワンダーパーク（雲の上のスイーツ遊園地）の仕掛け:
  - **ぷにぷにジャンプ**: ケーキタワーのらせんの1段目にあるピンクのパッド。ダッシュ中に踏むと、1つ上の段まで大ジャンプ（近道）
  - **もちフック**: ヘアピンでドリフトボタンを押しっぱなし → もちが伸びて塔にくっつき、ぐるっと回る。出口で離すとダッシュ
  - **ビヨーン橋**: 伸びるもちの橋。まん中でドリフトボタンを押すと、向こう岸まで大ジャンプ（近道）

## ファイル

ゲームはぜんぶ `index.html` 1つに入っています（three.js r128 を使用）。
ブラウザで `index.html` を開けば、そのまま動きます。

## みんなで直すときのルール

1. **直す前に、必ず最新を取ってくる**（GitHub Desktop なら「Fetch origin」→「Pull origin」）。
2. **何を直すか、先に声をかける。** 全部が1つのファイルなので、2人が同時に同じ所を直すとぶつかります。
3. **直したら、自分で一度遊んで確かめてから送る**（「Commit」→「Push origin」）。
4. 送ると、数分で公開ページが自動で新しくなります。
5. オンライン対戦の通信の中身を変えたときは、`index.html` の中の `NETV` の数字を1つ上げる（違う版どうしで走れないようにするため）。
6. アイテムの名前や見た目（きのこ・甲羅・スター・キラー・サンダー・バナナの皮）は、みんなで決めてから変える。
